# Aether League™ v1.4

League of Legends スタイルの 3D Web 対戦ゲーム（HoshiNet 開発）。
Next.js 16 + React 19 + Three.js + Tailwind CSS 4 で構築されたブラウザゲームです。

## 最新バージョンの内容（v1.4）

- **13人目のチャンピオン「ステラ」** 追加
  - 天使のような黄色髪のスターブレード使い
  - 普通攻撃：巨大な剣が前方160度にくるくる飛んでいく（近いほど高火力）
  - スキル1「スターバースト」（10秒CD）：360度に6つの星が出現し近くの敵へ飛ぶ
  - スキル2「ステラッシュ」（20秒CD）：敵の後ろ→前→後ろへ3段ダッシュ斬り（白黒+恍惚状態）
  - 必殺技「ステライド」：十角形の対角線ルートで連続ダッシュ斬り＋魔法陣ビーム
  - 負荷メータ：ダメージを与えると体力バー上に蓄積、満タンで360度剣舞攻撃
- **廃坑マップのBot落下バグ修正**（240秒で638回 → 0回）
- **ボルトの公平性パス**（Botが使うと強い問題の是正）
- **ルーミー健全化リデザイン**（ピンクのフレアドレス＋白ソックス）
- 廃坑マップの大幅軽量化（ジオメトリ結合・ライト削減）
- 60FPS最適化（シャドウパス間引き・30Hzプレート・ゼロアロケーション）
- リアルな落下演出（重力カーブ・タンブリング・カメラ揺れ・風SFX）

## セットアップ

### 必要環境

- Node.js 20+ または Bun 1.1+

### 手順

```bash
# 1. 依存パッケージのインストール
bun install        # Bun を使う場合
# または
npm install        # npm を使う場合

# 2. データベースのセットアップ（任意・対戦記録保存用）
bun run db:push

# 3. 開発サーバー起動
bun run dev
# または
npm run dev

# 4. ブラウザで開く
# http://localhost:3000
```

### ビルド（本番）

```bash
bun run build
bun run start
```

## ゲームの遊び方

1. タイトル画面 → PLAY
2. チャンピオン選択（13キャラ：ボルト / ハヤテ / ブレイズ / ミラ / ガロウ / クリスタ / ソーナ / パル / タンク / ルーミー / ヒヨリ / ノワール / ステラ）
3. マップ選択（クリスタルリフト / 廃坑 など）
4. マッチング → 8秒カウントダウン → 戦闘！

### 操作（PC）

| 操作 | キー |
|------|------|
| 移動 | 右クリック or WASD |
| 攻撃 | A + クリック / 左クリック |
| スキル1 / 2 | Q / W |
| 必殺技 | R |
| 指令ホイール | T 長押し |
| スコアボード | Tab 長押し |
| 一人称視点 | 視野ズーム（ホイール）で0まで |

### 操作（スマホ）

- 仮想ジョイスティックで移動・視点
- 右下のスキルボタン
- 右上でショップ / 設定

## プロジェクト構成

```
src/
  game/
    characters.ts     # チャンピオン定義（ステラ含む全13キャラ）
    maps.ts           # マップ定義（廃坑など）
    engine/           # 戦闘エンジン / VFX / 3Dモデル / ワールド
    net/online.ts     # オンライン対戦
  components/game/
    GameApp.tsx       # ゲーム全体の状態管理
    battle/           # バトルビュー
    screens/          # タイトル / メニュー / セレクト / リザルト画面
mini-services/
  battle-server/      # マルチプレイ用WebSocketサーバー
prisma/               # DB スキーマ
public/               # 画像素材・フォント
```
